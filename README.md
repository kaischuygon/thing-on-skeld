# The Thing On Skeld

A branching interactive short story ("hypertext narrative") built in plain HTML and CSS. You play a crewmate aboard the Skeld, a ship that has been infiltrated by an alien impersonating one of the crew. Each page offers choices that branch the story, with audio clips and an in-story dashboard showing a map of the ship and your task list.

**Play it:** https://kaischuygon.github.io/thing-on-skeld/

## Background

Originally built by Kai Schuyler Gonzalez as the hypertext narrative project for **ATLS 2200 Web** at the University of Colorado Boulder, Fall 2020, taught by Ian Hales. The story pages were last edited on 29 September 2020.

The source is kept as it was in 2020. The only later changes are fixes to four broken story links, plus this README and an `index.html` redirect so GitHub Pages opens the story.

## How to play

Open `startup.html` in a browser (or `index.html`, which redirects there), then launch `the-impostor.exe` from the taskbar. No build step or server is needed.
